# 마왕군 — 위계와 레벨 디자인

## 위계 구조

```
마왕 (제4의 벽을 어렴풋이 감지한 존재)
 ├─ 마족현자 — 진실을 알고 동조하는 유일한 협력자 (그림자 속 관찰자)
 ├─ 4대 군단장 (사천왕급) — 진실을 모르는 도구
 │   ├─ 마수군단장
 │   ├─ 환영군단장
 │   ├─ 불사군단장
 │   └─ 마룡군단장
 └─ 이름 없는 조연급 마족들
     (몽마 / 인간흉내자 등)
```

마족현자와 사천왕은 서로 위상이 다르다 — 도구(사천왕)와 협력자(마족현자) 사이에는 반목이 생길 여지가 있다.
(→ [마왕](마왕.md), [마족현자](마족현자.md))

이야기의 최종 목표는 처음부터 정해져 있다 — **마왕 토벌**. 공책RPG 시절부터의 목표가 그대로 본편의 목표로 이어진다.
(→ [메인 서사 축](../../설정/서사/메인_서사_축.md))

## 설계 원칙 — '어린아이의 머리에서 나온' 빌런

이 빌런 설정들은 어린 임자룡의 상상에서 비롯된 것이라는 전제를 따른다. 그렇기에 사천왕/군단장급 빌런은 **낯설고 실험적인 신선함보다, 누구나 한 번쯤 본 듯한 클래식한 원형**을 따르도록 설계한다. 변주와 개성은 주인공과 동료들 쪽에서 이미 충분히 담당하므로, 빌런은 오히려 정통성을 지키는 편이 낫다는 판단.

## 레벨 디자인 원칙

[00화 프롤로그](../../연재/00화_프롤로그.txt) 직후의 [서두 사건](../../설정/서사/서두_사건_던전공략.md)에서는 극복할 수 없는 상대를 시스템적 치트(글리치)로 넘어섰지만, 이후부터는 어느 정도 이야기의 순서를 따라 성장하며 진행한다.
주인공이 아무리 이 세계의 창조자이자 진행자라 해도, 매번 치트로 밀어붙이는 전개는 읽는 맛을 떨어뜨린다. 글리치는 예외적인 돌파구로 남겨두고, 4대 군단장은 정공법 — 성장, 동료와의 협력, 전략 — 으로 넘어야 하는 진짜 시련으로 기능해야 한다.
(→ [집필원칙 2. 개연성과 핍진성의 철저한 수호](../../설정/집필원칙.md))

이 레벨 디자인은 작가의 서사적 편의만이 아니라, **작중 내적으로는 [마왕](마왕.md) 자신이 설계한 단계별 시련**이기도 하다. 마왕은 용사가 이 관문들을 넘으며 성장하기를 기다리고 있다 — 자세한 이유는 [마왕.md](마왕.md) 참고.

## 제안하는 등장 순서 (조율 가능)

1. **마수군단장** — 직선적인 힘 대 힘의 첫 관문
2. **환영군단장** — 완전히 다른 종류의 시련(정신전·심리전)
3. **불사군단장** — 이름값 자체가 위협인 네임드 강자
4. **마룡군단장** — 마왕 직전, 가장 압도적인 최종 관문

각 군단장과 조우하기 전, 이름 없는 조연급 마족들이 발판 역할을 하며 서사의 리듬을 조절한다.
